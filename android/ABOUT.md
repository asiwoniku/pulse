# Earlier native Android prototype

The Kotlin/Jetpack Compose project in this folder is retained as an earlier
prototype. **The active Android app is now Flutter:** open the
[`../mobile`](../mobile/ABOUT.md) folder in Android Studio and follow its
instructions to run the offline preview.

This native prototype is not the canonical app and has not been validated as
the current Android deliverable. Do not configure or publish it in place of the
Flutter project.
